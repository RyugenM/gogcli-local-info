プライバシーポリシー

対象：有限会社メテオールの社内用Google連携ツール「gogcli-local」

アクセスする情報と目的

Googleで許可された範囲において、メール本文・添付・メタデータ、Driveのファイルとメタデータ、スプレッドシート、文書、予定、連絡先、タスク、アカウントの基本情報にアクセスします。検索、閲覧、集計、台帳更新、予定・メール等の業務管理に必要な範囲で使用します。

保存と保護

認証トークンは当社管理の認証保存領域で管理し、この公開サイトや公開リポジトリには保存しません。取得した業務データは、作業に応じて当社管理の端末、作業用ファイル、業務記録や承認済みサービスに保存されることがあります。不要な作業用データは業務上必要な範囲で整理し、会計などの記録は必要な保存期間に従って保管します。

外部サービス・AI支援

AIによる業務支援と併用する場合、取得情報のうち業務に必要な内容が、当社が利用を承認したAIサービス等に送信・処理されることがあります。その際は、対象データに適用される守秘義務・承認規則と各サービスの契約・設定に従います。すべての処理が端末内だけで完結するものではありません。

利用・共有の制限

Googleユーザーデータを販売したり、広告配信・広告ターゲティングの目的で利用したりしません。業務に必要な承認済みの処理または法令上必要な場合を除き、外部への提供は行いません。Google APIから取得した情報は、Google API Services User Data Policy（Limited Use要件を含む）に従って扱います。

許可の取り消し・削除

アカウント所有者はGoogleアカウントの接続管理画面からアクセス許可を取り消せます。取り消しにより今後のアクセスを停止できますが、すでに保存された業務記録が自動削除されるわけではありません。保存済みデータの削除は、法令・業務上の保存義務を踏まえて当社が対応します。

この説明サイトについて

当社独自のアクセス解析、広告、入力フォームは設置していません。ホスティングにはGitHub Pagesを利用し、GitHub側でアクセスログ等が処理される場合があります。
